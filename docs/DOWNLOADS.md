# Download and run CIQ Developer Terminal

**Created by Stefano Roman Gunness · Powered by OpenCode**

Download only from [this project's GitHub Releases](https://github.com/stefanoromang/ciq-developer-terminal/releases).
Use the files actually attached to the release. Source-code ZIPs generated by
GitHub are not ready-to-run desktop apps.

## Windows — x64

Choose one:

- **`windows-x64-setup.exe`:** a normal-user installer. Start it without
  “Run as administrator.” The installer does not allow elevation. Use a
  destination in your own user profile.
- **`windows-x64-portable.exe`:** run directly; no installer. The application
  still stores its settings/history in your user application-data directory.
  “Portable” here means no installation, not that all data lives beside the EXE.

The preview is unsigned; SmartScreen can warn. If organizational policy blocks
unsigned apps, contact your IT team. Do not disable protection or elevate the
program to work around policy.

## Linux — x64 desktop

Extract the downloaded archive into a directory you own:

```sh
mkdir -p "$HOME/Applications/CIQ-Developer-Terminal"
tar -xzf "$HOME/Downloads/CIQ-Developer-Terminal-0.2.0-linux-x64.tar.gz" \
  -C "$HOME/Applications/CIQ-Developer-Terminal"
```

Open the extracted directory, which may contain one additional top-level
folder, and start its `ciq-developer-terminal` executable. From that folder:

```sh
./ciq-developer-terminal
```

No system package installation is required by the archive. A supported desktop
environment must already provide Electron's shared libraries and unprivileged
user namespaces. Debian 12/13 desktop environments are the intended Debian
targets; an Ubuntu CI smoke test alone is not proof that every Debian machine
works. Minimal, headless, older or restricted Linux installations may require
administrator-provided prerequisites. CIQ does not turn off the sandbox.

If a Linux keyring is unavailable, choose session-only key storage. The app
rejects Electron's insecure `basic_text` credential backend.

## macOS — Apple Silicon

Extract the macOS arm64 ZIP and move the `.app` into `~/Applications`, not the
system `/Applications` folder. Open it from Finder. Preview downloads are
unsigned/not notarized. Do not disable Gatekeeper to install them.

## Verify a download

Compare the SHA-256 hash with the checksum file attached to the same release:

```powershell
# Windows PowerShell
Get-FileHash .\CIQ-Developer-Terminal-0.2.0-windows-x64-setup.exe -Algorithm SHA256
```

```sh
# Linux
sha256sum CIQ-Developer-Terminal-0.2.0-linux-x64.tar.gz

# macOS
shasum -a 256 'CIQ-Developer-Terminal-0.2.0-mac-arm64.zip'
```

Use the actual name of your download if it differs from these examples.

## First launch

1. Choose **Use free models** to start immediately with OpenCode's free coding
   models. No API key is required.
2. Open a project folder and start a conversation.
3. Optional: connect a CollectivIQ Developer/Gateway key, or add another
   provider in **Model library → Connect another provider**. Never put a key in
   a GitHub issue or send it in chat.
4. Add only trusted MCP servers, and approve tool execution when appropriate.

Free model availability and rate limits are controlled by OpenCode. CollectivIQ
model access, costs and Best of the Best availability depend on the account and
API catalog.

## Updates

CIQ 0.2.0 and later check this repository's GitHub releases about twice a week,
catch up on launch, and download newer versions automatically. Each download is
SHA-256 verified before installation, and CIQ asks before restarting. The 0.1.2
preview has no updater, so install 0.2.0 manually once.
